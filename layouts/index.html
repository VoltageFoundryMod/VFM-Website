Get the VCV modules

The whole catalog is bundled into a single VCV Rack plugin, {{ site.Title }} — coming to the VCV Library soon. Until then, build it from source or grab a release from the plugin repository.

VCV Library (soon!) Repository Sources on GitHub

Build the VCV version yourself

git clone --recursive \
  {{ site.Params.plugin_repo }}
cd VFM-Modules
make
make install

Requires the VCV Rack SDK. See the repository README for details.

Build the hardware

Every module is fully open hardware — schematics, panels and firmware are all published. Order the PCBs and panel, source the parts, and flash the firmware to hold the real Eurorack module in your rack.

Hardware repository All module sources

Flash a module's firmware

git clone --recursive \
  {{ site.Params.github_org }}/ForgeSeries-CLK
cd ForgeSeries-CLK
pio run -t upload

Built with PlatformIO. Each module's repository has its own build & calibration guide.
